# 🎮 ICT Minecraft 服务器

> 加入并游玩 ICT，即表示你愿意阅读并遵守《服务器手册》及相关规则。  
> 服务器的运营和管理遵守中华人民共和国法律法规。

## 关于 ICT

ICT 是一个从 2019 年 11 月持续运营至今的 Java 版 Minecraft 原版生存社区。

我们不追求把服务器做成一个热闹但短暂的地方，更在意玩家能不能在这里长期生活、建设和交朋友。有人愿意花几个月甚至几年完成一座建筑、一条铁路或一套机器，这些投入应该被认真对待，也应该被好好保护。

我们坚持使用原版玩法，不用 Mod 改写游戏规则。你可以自由建造、探索、经营和合作，也可以按照自己的节奏游玩。服务器存在的意义，不是替玩家规定一种玩法，而是尽量守住一个稳定、公平、值得长期投入的世界。

## 我们的使命

**让一群认真对待游戏、也尊重他人的人，在同一个持续存在的世界里，留下真正属于自己的作品和故事。**

为此，我们会坚持几件事：

- 保留 Minecraft 原本的探索、建造和生存体验；
- 保护玩家的建筑、资源、机器和长期投入；
- 鼓励合作，但不强迫所有人采用同一种玩法；
- 用清楚、统一的规则处理破坏、盗窃和恶意行为；
- 维护一个可以放心交流、愿意长期回来的社区。

## 为什么需要白名单审核？

白名单不是为了把人挡在门外，而是为了让每一位已经在这里投入时间的玩家，知道自己的作品和体验会被认真保护。

ICT 的玩家来自不同地方，有不同的性格和玩法。人数越多，越需要在加入之前确认彼此对基本规则的理解：不破坏他人建筑，不盗取他人财物，不恶意干扰他人的游戏，不把个人情绪带进社区。

申请只需要花大约 10 分钟。我们希望加入的人，是真心想在一个长期、稳定、彼此尊重的原版世界里游玩的玩家。
